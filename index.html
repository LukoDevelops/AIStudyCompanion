                    AI Study Companion

                    CM3070 final project · University of London and Goldsmiths.

                    What it does

                    • Finds useful passages across your own sentences
                    • Reads audio, scanned text, and images on this device when you attach them
                    • Builds local questions, with an optional cloud-assisted writing mode

                    A quick note before you rely on it

                    • This is a study aid, not a promise of better grades
                    • Source links show traceability, not full fact-checking
                    • You never need a paid API to use the local features

                    Everything runs in this browser unless you choose an optional cloud helper.
